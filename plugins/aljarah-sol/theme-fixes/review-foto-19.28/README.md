# Thema 19.28 – Review-foto per kleur

Kopie van 19.27 (live). Niet gepubliceerd.

Met `?resena=1&variant=<id>`:
- De productpagina kiest die variant.
- Het Judge.me-formulier toont de foto van die variant (vooraanzicht van die kleur) in plaats van de hoofdfoto.
- De kleur komt achter de productnaam, bijvoorbeeld "… · Negro".
