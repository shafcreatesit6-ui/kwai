name: customer-support
description: Draft Aljarah Sol customer service replies (orders, sizing, returns, product questions). Use when answering a customer email or message for the store.
---

Follow the `brand-voice` skill. Reply in the customer's language (default Spanish, tú).

1. Look up live data first with the Shopify tools (order, product, inventory). Never guess stock or order status.
2. Structure: thank them warmly → answer directly → next step → sign off "Un abrazo, el equipo de Aljarah Sol".
3. Sizing: recommend from the product's size range; if between sizes, suggest the larger one for sets and the smaller one for seamless leggings, since those are compressive.
4. Never promise refunds, delivery dates or discounts that aren't confirmed. Flag these for the owner.
5. Save replies as drafts. Don't send without approval.
